# 原 Random Forest 结果复核

桌面 `rf_results_20261126(1).zip` 与下载缓存的 SHA-256 相同。逐一核验导出清单中的 80 项文件和运行清单登记的锁参哈希。旧结果来自 `c490657848ee56884d384d04`。该结果包保留已选模型的逐周评分和概率。逐拟合权重留在原运行目录。见 [压缩包核验和锁参摘要](original_run_audit.json)。

## 概率和选参

- 沪深 300 与中证 500 的 Z* 分类锁均选中 256 棵树、深度 12、最小叶 2、特征比例 0.35、行抽样 0.85 和 balanced。旧版用 3060 选参。沪深 300 的 Z* 开发损失按种子为 0.18882、0.39697、0.59335。三种子均值为 0.39305。[旧版 B 概率复算](original_b_probability_replay.csv)
- 对沪深 300 的 Z* 旧 B 期 150 周，用同周训练频率混合原生概率。25% 收缩把三种子平均 Log Loss 从 0.39305 降至 0.19516，Brier 从 0.07562 降至 0.07308。同期历史频率 Log Loss 为 0.20621。本项直接使用旧预测概率，未拟合森林。[旧版 B 概率复算](original_b_probability_replay.csv)
- 旧 C 期沪深 300 的 Z* 三个种子分别有 4、3、4 次真实类别概率触底，合计约占对数损失的 81.3%。原 C 期四市场三信息集的 12 个分别调参分类结果均高于历史频率的 Log Loss。每市场评分 194 周。[旧版 C 概率审计](original_c_probability_audit.csv)

## 回归和宏观依赖

旧 C 期原 Z 在沪深 300 的 Amihud MAE 下降 18.59%，但波动率 MAE 上升 12.76%，五维损失上升 3.07%。Z* 在全 A 的换手率 MAE 下降 13.92%，波动率 MAE 上升 21.22%，五维损失上升 3.08%。这两组结果提示逐目标收益和综合误差会有不同方向。[旧版 C 逐目标结果](original_c_regression.csv)

旧 C 期分别调参分类的宏观分裂平均占比在原 Z 为 51.3%，在 Z* 为 49.3%。原版月内扰动诊断、实际抽样特征数和叶支持随审计保存。月内低频宏观值可能完全重复，需同时查看列是否发生变化及实际配对损失。[分裂与扰动摘要](original_run_audit.json)

前两模型的 20 日结果延续原 Z 定义。已独立重训的 60 日 RBF-SVM 实验中，分别调参时八个市场任务组合有七个 Z 模型选中零宏观权重。全 A 分类选中正权重，增量为 +0.0004，95% 区间为 [-0.0103, +0.0180]。据此保留允许零修正的对照和逐目标报告。60 日结果的标签、输入和区块宽度独立登记。[60 日 RBF-SVM 实验](https://github.com/sjyinzju/MLEC/blob/562ed52b6c86a1a77e379cac892713c837f37f85/reports/model_build/rbf_svm/retuned_60d_20261126/report.md)
