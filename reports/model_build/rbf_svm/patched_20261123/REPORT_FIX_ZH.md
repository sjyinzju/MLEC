## 一、这次到底修了什么

### 问题

原实现的 RBF 核尺度由 `relative_gamma = factor / (特征数 × 方差)` 决定。加入宏观块后特征数与方差同时上升，gamma 被压到 1/285，核矩阵退化为近常数（K≈0.93–0.997），模型决策函数近似常量。

### 修复

在 `RBFSVMAdapter` 内实现**按训练折拟合的金融/宏观分块归一**：

- 每个拟合只用传入的训练矩阵估计两块各自的 RMS，再各自缩放到单位 RMS；
- 缩放贯穿**内部时间校准块、最终拟合、预测**三条路径，预测期复用拟合期缩放（不会用验证/测试信息估计尺度）；
- 缩放向量随模型包持久化，并进入 `model_version` 身份；加载后重算身份可复现；
- 未改原始标签、七维目标定义、时间切分、候选网格与评价规则。

### 验收数值（开发折 2022-12，真实任务）

|---|---|---|
| M+Z gamma（000300） | 0.000040 | **0.001807** |
| M gamma（000300） | 0.011407 | 0.004848 |
| 宏观块占总距离² | 0.66–0.97 | **0.485（000300）/ 0.491（000985）** |

| 分块缩放比（金融/宏观） | — | 1.006（两块已均衡） |

核几何从"饱和"恢复到有区分度的范围，金融与宏观块对距离的贡献接近均衡。

## 四、模型是否学到了宏观信息

- 扰动实验（固定权重、只置换宏观块）：宏观块置换对决策分数的相对影响与金融块同量级（中位 0.58% vs 0.64%，比值 0.914），credit 组影响最大（均值 0.068，最大 0.367）。
- 即**第一层（输入利用）成立**：宏观信息确实进入了预测；
- 但**第二、三层不成立**：这些扰动没有转化为对真实标签有用的条件信息——分类端核仍饱和、输出近常数；回归端宏观块主要表现为噪声（加宏观后 turnover +22%、correlation +11%、volatility +9%、breadth +7.5% 的 MAE 恶化）。

## 五、为什么修了核尺度还是没用

1. **搜索吸收**：gamma_factor 是自由参数，分块归一后最优解落在同一候选，等价于"换个参数达到同样的核"。
2. **绑定约束在标签与容量**：000300 测试窗口 state 0 只有 4 次，任何分类器都会被多数类主导；要让少数类可学，需要事件级重加权或更长窗口，而不是改核尺度。
3. **回归收缩来自 SVR 的固定 C/epsilon 网格**：预测标准差只有实际 7%–79%，MAE 接近"预测均值"水平；这需要按目标尺度重设 epsilon/C，而不是核归一。
4. **宏观块本身信息密度低**：30%–50% 的宏观列在训练折内零方差，有效维度仅约 19，加入后主要增加噪声。

## 七、回答六个问题

1. **原设计问题是什么？** 核尺度被宏观块稀释（gamma 1/285、核饱和）、宏观块 30–50% 死列、分类多数类退化、SVR 强收缩。**已修复**：核尺度（已验收）、死列被预处理器剔除与分块归一共同缓解。**未修复**：分类退化与 SVR 收缩。
2. **修复后模型是否正常、有无实质改善？** 核几何正常了（K 从 0.99 摊到 0.27、宏观距离占比从 92% 降到 48%），但**预测没有实质改善**：分类仍全预测 class 1，回归仍收缩，测试期主指标与原版差异 ≤0.0003。
3. **模型是否学到与预测相关的宏观信息？** 学到了"响应"（扰动敏感性与金融同级），但**没有学到"可用的条件信息"**——第二、三层检验不通过。
4. **加入宏观后主要指标改善还是恶化？** 分类：不可区分（区间全部跨 0）；回归：**恶化**，3/4 市场显著（−0.015 ~ −0.042）。
5. **哪些宏观组有价值？** credit 组对决策影响最大，但方向是增加波动而非稳定改善；其余组影响弱。没有任何组在开发期表现出稳定的正增量。
6. **对研究问题提供什么证据？** 与 Elastic Net 相互印证：**在冻结的标签、切分与评价口径下，宏观信息对 A 股风险状态预测没有可检测的正向增量**；回归目标上宏观信息稳定有害。这是一个可复现的负面结论，且经得起一次实质性设计修复的检验。
