# 发布时间与版本验收

`research_available_at <= asof_time` 为硬门槛。官方 NBS 原公告时间由保存的官方检索响应 docDate 佐证；PBOC 迁站后的网页时间可能变成 2025 年，改用保存的官方目录相邻日期。公告只有日期时一律设北京时间 23:59:59，因此周五公告不会进入当日 18:00 预测。PMI 统计月份可在日历月末前公布，不等于未来数据。

| 等级 | 依据与用途 |
|---|---|
| strict_pit_eligible | 逐期官方正文数值 + 官方公告日期，保留后续版本；可用于公告版本实验 |
| conservative_release_reconstructed | Shibor、CFETS 国债、SAFE 官方历史报价；日期末可用，但缺更正日志，明确限制 |
| latest_vintage_reconstructed | 原交付和第三方历史表未证实当时版本；可得时间为实际获取时间，不能用于 2015 年回测 |
| blocked | 字段/口径无法可靠识别，禁止模型输入 |

主核心组采用“官方公告 + 官方金融报价日末”政策，不标成全变量 strict PIT。未来若获得金融报价更正档案可建立更严格版本。原始、标准化、特征三层分开；后续旧季度修订先在季度内选版本，再选最近经济季度。不能按最后一次发布日期把旧季度当成最新季度。

实际源文件和 SHA256：`data/metadata/raw_source_registry.json`；官方 URL、发布日期、数值原文路径和转换说明：macro_facts / data_lineage。DR007 同伴接口返回不同期限字段，未能取得可验证历史，不替换为 R007/FDR007。进出口目前仅事后历史候选池；不纳入主实验。
