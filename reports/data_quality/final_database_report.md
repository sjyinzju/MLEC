# MLEC 最终研究数据库

版本：`practical-research-data-v5`。结论：**UNRESOLVED_REQUIRED_DATA**。

处理后的数据库和统一接口可以用于后续开发，合格指标可以分别使用；尚不满足“所有必需字段全部正确完整”的整体 DATA READY 条件。下列缺口没有被改名为可选，没有填零、取平均或混用不同统计定义。未训练模型、运行 Benchmark、调参或生成预测。

## 权威数据与读取

物理路径沿用 v4；当前版本以 [注册表](../../data/metadata/dataset_registry.json) 为准。

| 内容 | 权威路径 | 规模与范围 |
|---|---|---|
| 七个宽基指数 | `data/standardized/market/v4/index_daily/` | 21,665 行，2014-01-02—2026-09-22，每指数 3,095 个交易日 |
| 沪深股票行情、每日基本指标 | 同目录 `stock_daily_observations/`、`stock_daily_basic_observations/` | 各 11,981,370 行，保留退市证券 |
| 复权因子 | 同目录 `stock_adjustment_observations/` | 12,333,672 行；每个实际报价日均有正因子，身份区间外记录须排除 |
| 证券身份与交易状态 | `stock_master_history.parquet`、`stock_trading_status/` | 5,555 个法律证券身份、5,559 个代码区间；正常报价、源记录停牌、官方区间停牌分别保存 |
| 成分与权重 | `index_constituents_history.parquet`、`index_weights_history/` | 38 次深证成指公告调整；七指数各 140 个月度快照、合计 576,892 条权重 |
| 活跃度与金融扩展 | 同目录交易所统计、涨跌停、融资融券、资金流、沪深港通、公司行为表 | 沪深统计均覆盖 3,095 个交易日期；各字段和证券范围仍须按字典过滤 |
| 宏观事实与版本 | `data/standardized/macro/v4/` | 47,717 条来源/版本事实；不是 47,717 个互不重复统计期 |
| 市场扩展与宏观特征 | `data/features/{market,macro}/v4/` | 五种宏观质量视图；连续市场扩展；按历史时点对齐 |
| 冻结研究样本 | `data/research_v2/` | 原 599 个周度候选时点、H5/H20/H40 标签、风险集及时间折 |

读取入口为 `scripts.final_data_foundation.research_inputs.load_dataset`，支持 M、M+Z、指定组和指定变量；示例见 [README](../../README.md)。请显式选择 `quality="historical_reconstructed"` 并使用返回的资格掩码。默认仍为 conservative；599 个候选行不等于 599 个可训练样本。这里不报告模型效果。

成分查询使用 `membership.load_index_members(..., mode="monthly_snapshot")`，最多沿用 45 天；不声称精确逐日权重。公告 effective 模式仅覆盖收录的可信区间。资金流等供应商扩展表的代码可能使用历史别名，必须通过 `stock_master_history` 的法律身份及有效日期与正式行情连接，不能仅凭字符串代码判断缺失。

分红事件表有 393 条源记录缺少公告日期，含提议、预披露及部分历史实施记录；不据此倒填历史可得时间。其主键改为完整且唯一的来源记录 ID，原自然事件字段仍保留。

## 本轮实质补充与修复

- 新增 61 期人民币贷款累计流量、40 期社融累计流量；另补 2018 年社融扩围附近 5 个累计期和 8 个已发布的同范围回溯月值。派生值按同年、同单位、同币种、同统计范围求和，可得时间不早于任一父记录。
- 2018 年回溯月值在 9 月公布，未提前放入 1—6 月预测。历史累计求和可能与后来修订的官方累计不同，二者不混称同一版本。
- DR007 的可信历史值纳入历史重建视图，保留实际采集时间和明确报价时钟；与官方重叠的 30 条报价核对一致。缺少全部首次版本不再等同于数值缺失。
- 依据公司公告修复 4 个复权事件边界，影响 3,507 条因子。000011 采用税前现金除息连续性，600733 按原流通股股东两次权益顺序相乘；不冒称现金再投资总收益。之前 000545 的转增修复继续保留。
- 从同日成交量与自由流通股本派生 23 个自由流通换手率。当前 61,368 条 PB 空值有此前已披露、账期足够近的非正净资产依据，按正净资产估值惯例单列；这不是数学上无法计算负 PB 的断言。
- 移除 11 个有停牌证据、无实际报价的每日基本指标占位行；其孤立量比值保留为排除依据，未当作真实交易指标。
- 补入上交所 2014 年 245 日、1,960 行统计；深交所缺失 253 日的 1,257 条股票类别统计；修正 2026-05-12 四类股票统计全零错误。
- 深交所金额、市值单位按官方表核验为元；股票成交量、总股本、流通股本核验为股。通过三项金额总量一致性筛选替代来源后，补入 6,862 个数量字段，保存可复算的数值父记录。未按量级猜测修正不合口径的旧来源行。

| 每日基本指标 | PB 13,936 个、自由流通换手率 16 个仍缺；股本分母相关 2,840 个字段例外未裁定 | 定向重取 281 只证券仍无补值；按字段质量屏蔽。另有 460,960 个例外仅符合精度解释，并非独立认证 |

| 国债收益率与利差 | 2014 年 1Y、10Y 各缺 245 日，派生期限利差因此缺 245 日 | 注册口径为 CFETS 11:30 曲线；不将不同的中债曲线或月度值拼成逐日报价；2015 年后已有值可用 |

| 资金流（既定可选扩展） | 实际交易日仍缺 2,558 条；82 条无行情日资金流隔离 | `UNAVAILABLE_OPTIONAL_DATA`；不同供应商资金流分类不互相冒充 |

## 对研究维度的支持

| 市场维度 | 数据支持 |
|---|---|
| 趋势 | 七指数 5/20/60 日收益与原冻结趋势指标；中证1000冲突窗口排除 |

| 交易活跃度 | 成交量、成交额、换手率和交易状态；低活跃度不等同流动性危机 |

## 验证与保留范围

全量技术检查结果在 [验收汇总](../../data/metadata/final_validation.json)：正式表主键与字段、完整真实价量、身份区间、报价因子覆盖、宏观派生公式、五种视图的时间与口径、35 种信息集接口及冻结哈希。通过技术检查不自动消除上述真实缺口。

保留标准数据、直接研究输入、来源链接/统计定义/公式父值、必要维护代码和既有正式成果。删除原始下载、复现备份、请求/运行日志、大型逐行审计及重复供应商中间层；具体磁盘体积在 `data/metadata/delivery_storage.json`。原始数据由用户及同伴保管，未重新创建本地原始备份；不承诺逐字节离线重建。

外部 `E:/QuantData` 与 `E:/quant` 仅作读取，未写入或清理。Git 历史未改写；大型金融标准数据、模型二进制及本地依赖不随 GitHub 克隆分发，完整数据库在当前本地仓库。
