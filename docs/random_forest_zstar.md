# Random Forest 与增强宏观信息 Z*

2026-11-26 登记。四市场、周度 20 交易日、原 GMM 词典和七个连续目标保持固定。Z* 是原封版上的版本化扩展。历史测试期此前已经查看，本轮属于历史复核。

## 正式流程

三信息集使用同一个扩展视图身份以校验配对，原始 M、M+Z 的值和键来自原封版。M+Z* 加入增强纯宏观和有双重谱系的宏观金融交互。五组删除与加入投影可单独研究，核心管线只计算三组。分类使用原生概率和字典顺序，缺席类别补零，单类折失败。回归使用原生七输出森林，在各训练折内使用既有目标变换等权平衡五维，预测恢复原单位。训练的有限数值清洗与缺失适用性由公共折内预处理处理。

每个市场、任务、信息集使用同一批 18 个候选及 36 个开发月。每项分裂特征比例为 0.35、0.70 或 1.00。六种预先登记的组合覆盖树深 3–12、最小叶 2–12、128–256 棵树、0.75–1.00 样本比例，分类覆盖自然类别权重、balanced 和 balanced_subsample。相同抽样比例对应的候选列数随信息集实际维度变化。候选共用种子 3060。分类以对数损失、回归以初始固定尺度的五维等权平方损失选模，按真实评分周平均。任一必需月失败则整候选无资格。并列按更浅的树、更大的最小叶、较小的行抽样和特征抽样、较少树、无类别权重以及候选 ID 决定。

独立调参对照采用三个信息集各自的胜者，固定参数对照把每个市场任务的 M 胜者分别装入三个信息集。锁前计算开发预警工作点。种子 3060、3061、3062 分别计算损失，再对同日期的配对损失取均值。对三个配对比较使用同步周区块 bootstrap、原主块 8 周及 4/12 周敏感性。保留历史频率、当前状态、连续过去窗口持续值和训练均值对照。袋外估计未参与选模或评价。

C 期组别扰动在同一月内循环置换封版预测行的原始宏观块，在保持 M 的情况下重算相关交互。它是已拟合模型的验证期依赖诊断，分析时同时看实际配对损失。切分次数、叶支持、实际分裂抽样列数以及各目标在适配尺度上的分裂误差减少均随结果保存。上述诊断不参与锁参。

## 执行入口

先安装 `requirements-experiments.txt`。独立运行 `python -m scripts.market_state.experiments preflight --model random_forest` 检查数据与环境。小规模技术入口为 `python -m scripts.market_state.experiments.forest_technical --execute`。正式启动一次执行完整链路。

```sh
python -m scripts.market_state.experiments pipeline --model random_forest --suite full --cpu-workers 2 --cpu-threads 1 --resume --execute
```

结果位于 `results/random_forest/<run_id>`。中断后重用同一启动命令。增加 worker 数不改变拟合身份，切换每任务线程数会改变身份。模型验收与正式报告分别保存。
