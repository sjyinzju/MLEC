# Random Forest 与增强宏观信息 Z*

2026-11-27 登记的 `random-forest-zstar-v2` 使用同一原封版、原四市场、周度未来 20 交易日、GMM 三状态及七个连续目标。M 与 M+Z 来自原始版本。M+Z* 使用经过独立验收的 Z* 扩展及宏观金融交互。原 Z 与 Z* 的来源和差异见[宏观特征契约](z_star.md)。本次实验属于历史测试范围上的修订复核，旧运行 `c490657848ee56884d384d04` 保留。

## 分类概率

自然类别先验按训练折已成熟标签的未加权次数计算，每个固定字典类别加一伪计数。森林原生概率对齐字典顺序。正式输出 `(1 − α) × p_RF + α × p_history` 使用正 α，带完整类支持。单类训练折按已有契约失败。原生概率、先验、选定 α 与最终概率分别保留，可配对重算。评分的 Log Loss 下限保持 `1e-15`。模型中未增加另一个概率校准器。

对同一个森林，从已保存的原生概率计算 α=0、0.01、0.05、0.10、0.25 的 Log Loss 和 Brier。α=0 为原生对照。正式参数从四个正值中选，主准则为同周平均 Log Loss。相同损失时取较大 α。自然权重和 balanced 均进入 B 期搜索，均在自然分布的评分周上比较。

## 选参与正式对照

24 个候选覆盖各结构参数的两两组合。森林使用 256 或 512 棵树，深度 3、5、8、12，最小叶样本 4、8、12、16，分裂特征比例 0.35、0.70、1.00，样本比例 0.75 或 1.00。配置中的生成种子固定。特征比例 1.00 提供全列参与的对照。分裂报告同时记录名义比例实际对应的绝对宽度、各组列数和切分使用。

每个市场、任务和信息集用相同的候选、种子和全部 36 个开发月。筛选种子为 3060，复核入围的三个结构使用 3060、3061、3062。分类在筛选时纳入概率收缩。复核按相同周及相同种子比较损失，最终参数取三种子的平均损失最小。保留筛选与复核的逐种子记录、均值及波动。任一必需月份或种子失败使候选失去资格。无额外的测试选参入口。

各信息集独立选择赢家，同时执行固定 M 参数的配对对照。分类复核和选定开发可复用同一原生森林及预测证据，概率输出的身份随收缩系数变化。两阶段的物理复用、成功记录哈希和锁定证据保留。标准拼接模型通过配对估计宏观增量。统计使用同步周区块 Bootstrap，主块 8 周，4 周和 12 周为敏感性对照。

## 回归与机制

七个目标使用共享的折内目标适配，预测回转原单位。选参使用冻结初始尺度、维度内平均及五维等权。有限开发对照使用相同样本、森林结构和种子比较原生共享分裂与七个独立目标森林。逐目标森林在 6 个市场×信息集组合中改善 5 个，五维损失相对平均下降 3.65%。正式优化版在三个信息集均使用逐目标森林。原生多输出保留为对照。[配对开发指标](../reports/model_build/random_forest/final_optimization/regression_development.csv)

辅助结构从严格时间折外的金融预测构造残差。每半年只使用块起点前成熟的金融训练标签，每个外折的残差森林只接收该外折已成熟的折外残差。使用共同的浅树比较金融修正、原 Z、Z*、去掉显式交互的 Z* 和五组增强宏观。修正系数备选为 0、0.25、0.5、1，零修正逐项复现金融锚点。使用 2020–2021 的指定开发折选择修正强度，在 2022 的指定开发折确认。沪深 300 的两个宏观组合超过对两种金融参照的 2% 门槛，中证 500 未达到。残差修正登记为开发诊断。[残差确认对照](../reports/model_build/random_forest/final_optimization/residual_confirmation.csv)

月内置换和 13 个日历周偏移扰动保留同一金融列并重算交互。后一项用过去周完整宏观向量缓解低频宏观列在月内无变化的问题。按组保存评分差异和实际覆盖。扰动仅描述固定森林对输入的敏感性。

## 执行与回执

```sh
python -m scripts.market_state.experiments preflight --model random_forest
python -m scripts.market_state.experiments smoke --model random_forest --execute
python -m scripts.market_state.experiments.forest_technical --execute
python -m scripts.market_state.experiments pipeline --model random_forest --suite full --cpu-workers 2 --cpu-threads 1 --resume --execute
```

最后一条命令供同伴正式运行，完成后自动写报告并导出 ZIP。中断后使用原命令和输出目录，worker 数可以调整，每任务线程数属于运行身份。明确指定已完成目录可使用 `export --model random_forest --run <run_dir>` 重做导出。监督训练需要显式执行，安装、预检、普通 pytest、计划、汇总与打包均不触发监督拟合。

原运行审计、有限真实开发期结果和当前源码回执见[交付证据](../reports/model_build/random_forest/final_optimization/)。运行入口见[同伴说明](../launchers/random_forest/README_START_HERE.md)。
