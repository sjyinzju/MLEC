# 研究限制与后续正式评价

1. 核心月度 CPI/PPI/PMI/新订单/M2 有逐期官方正文和日期证据；Shibor 为官方历史报价档案，没有更正版本日志。全核心组采用明确的日末保守可得政策，不能等同完全严格 PIT。国债与汇率同样保留档案限制。
2. 原交付、QuantData 和第三方历史表中的事后修订值不进入历史主实验。M2 的跨来源差异保留原公告版本。东方财富贷款字段与公告有显著差异，未查明定义前标记 blocked。进出口历史公告版本仍未认证，external 组 blocked；DR007 尚缺可核验长历史。LPR 及 M1 新定义不能人为延伸到 2015 年。实际缺口逐条列出，不宣称候选池全部认证。
3. 工业/零售春节合并发布、贷款部分季度报告仅给累计等属于明确口径约束。不能把 1—2 月同比当作 2 月同比，不能用累计同比相减得单月同比。YTD 派生 change 只是相邻已发布累计值变化，不命名为单月流量；年度重置需结合统计含义解释。
4. 原协议初始参考期阈值用 2015—2019 冻结；本轮不重估标签。内层参考期选择复用这些冻结状态，不能解释为当年已经部署的完全实时系统。2020 年之后才是本轮正式开发预测起点。
5. 开发期只有 3 年、99 个市场风险有效 OOF 周及少量唯一压力事件；H20 窗口重叠。区块 bootstrap 和事件 Wilson 区间仅作有限样本描述，不能用周数充当独立事件数。
6. 多个经济组和模型比较是开发实验，未校正多重比较。full 组维度高于样本能充分支持的规模，必须保守解释。不同共同样本版本不能直接比较总指标，应以每组重训的 M 为配对基线。
7. 校准器与超参选择共享外层训练内的 OOF 折。主要结果固定使用原生概率，校准只作诊断。预警阈值在开发期选择并在同开发期展示，存在选择乐观偏差；不能当独立预警成功率。
8. 报警提前量相对于冻结 trigger/onset，不表示尚未出现市场下跌；逐事件报告保留报警时回撤。政策/经济数据只能支持预测关联，不能从增量预测误差推导因果作用或交易收益。
9. 最终 2023+ 评价尚未执行。正式使用前冻结唯一主模型/主组、缺失规则、质量版本、超参预算、校准方案、误报预算/阈值及稳健性矩阵，记录审批版本后单独执行一次。不得用最终期结果回选变量、阈值、标签或论文主结果。
10. 源站历史页可能修订；本地保存本次证据快照和哈希，不声称已取得互联网历史页面的每个发布版本。缓存是可复现依据；新下载须建立新数据版本。原采集项目全程只读，未全量重新下载证券市场数据。

全历史核查：2025-01 M2 原公告未在当前央行目录中找到，保留事后候选值和转载线索而不自动认证。开发期核心月度覆盖齐全，但不能扩大为 2014—2026 全部月份均有严格公告版本。逐月详见 audit/framework/macro_full_history_gaps.csv。
