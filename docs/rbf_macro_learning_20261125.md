# RBF-SVM 宏观增量复核设计

实验登记为 `rbf-macro-learning-20261125-v1`。沿用 market-state-research-v3.0 封版、样本成员、标签成熟日、四市场、七目标、五维权重及所有统计和报警规则。2023 年起历史测试结果此前已查看，本次 C 是事后修订模型的固定方案复核。C 的结果不进入模型、参数、组、校准方法或预警工作点选择。

## 表示与核

保留 semantic-inputs-v2 逐列转换。加权核在每次拟合的实际变换后矩阵上用正式特征组清单绑定宏观列和源列缺失指示。剔除训练恒定列。每块以训练列均值中心化，除以块总体方差之和的平方根。LIBSVM 接收按金融、宏观顺序拼接的坐标，宏观坐标乘以宏观权重的平方根。核指数等于核尺度乘以金融距离平方与加权宏观距离平方之和。核尺度的基值固定为 1。宏观权重为 0 时直接使用金融坐标。变换列、来源组、中心和尺度随估计器保存。

完整表示保留全部封版宏观变换。精简表示保留最新值、相邻可比发布变化、日度指标 20 观测波动和缺失状态。精简与时钟表示在经济组内去除训练折上完全重复的列。发布时钟对照保留信息年龄和适用性、断档、缺失状态。相邻发布变化表示已观察数值的变化。主视图是历史重建版本。来源的可得时点约束与实际档案版本的可验证性分别审计。

## B 的 36 个评分月

- 两个核心信息集的分类和回归各比较 16 个候选。金融信息用四个核尺度，宏观信息用四个布局，包含 0 权重、相同核尺度及权重下的完整与精简表示、较小宏观权重与第二核尺度。零权重与金融基准共用核尺度 0.25 的四个求解器配置。分类比较两个 C、自然分类权重及均衡权重、旧式 OvR Platt 与正则化多项校准。分类的一组同参数比较隔离校准器，另一组隔离类别权重。
- 校准训练只读取内部前推折的原始决策分数和自然频率标签。内部训练缺类别则跳过该训练块并记录，外层评分保留不含少数类的周。正则化校准以平滑自然频率为截距锚点，对归一化分数每类斜率和截距修正分别加 L2 惩罚。原始分数的 softmax 作为同尺度概率诊断；时间折外分数上的校准器拟合概率标明用于校准器训练。
- 每个核布局的七个 SVR 各按固定初始尺度平方损失从同一紧凑 C/epsilon 列表选择。然后用原五维规则汇总七项最优损失选择共享核布局。训练和输出继续使用 TargetAdapter。选择以完整合法月份为条件，确定性平局规则在配置和候选比较顺序中固定。
- 五个单组加入、五个整组删除各覆盖四市场和两任务。固定组对照以 M+Z 开发期最佳正权重模型固定全部参数重拟合十二个信息集。当总体最优权重为 0 时，保留最优正权重模型供组对照，同时主结果保留 0。组重调覆盖相同评分周，组内使用同一四候选预算。时钟模式使用相同全宏观正权重模型的核与求解器参数。
- 每个市场的固定金融锚点和封版历史训练均值、持续值基线保留。若开发期主损失没有严格改善，使用预登记的固定金融锚点产生的时间折外残差，在外层训练成员内用成熟开发预测拟合带 L2 惩罚的宏观校正。校正模型不参与选择。在全部 B 月内联合置换验证期连续两周宏观块，每月只使用同一验证区间的输入，各列共用置换。
- 仍沿用未实现的数据协议扩展。额外发布滞后需要前一可比公布的原始事实链，市场模块与替代状态字典需要对应的单独协议和注册接口。
