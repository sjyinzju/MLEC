# Z* 宏观扩展与质量核查

`macro-z-star-v1` 在 2026-11-13 18:00（北京时间）的原封版上新增宏观表示。扩展沿用 `historical_reconstructed` 的准入时钟、607 个周度预测锚点和四市场的共同样本契约。纯宏观数据由 `features.parquet` 提供。市场相关交互在统一数据接口装配，其谱系同时标识宏观与市场父列。

## 发布记录与修复

| 序列 | 周度实际覆盖的经济期 | 同期持有周数 | 周内谱系同一期来源更替次数 |
| --- | ---: | ---: | ---: |
| 制造业 PMI | 143 | 464 | 0 |
| CPI 同比 | 144 | 463 | 0 |
| 实际 GDP 同比 | 49 | 558 | 0 |
| CNY 出口、进口累计同比（各） | 137 | 470 | 73 |
| 外汇储备 | 129 | 478 | 33 |
| DR007 | 607 | 0 | 0 |

- 原 `macro.align` 的年初重置保护只覆盖 `ytd_flow`。正式进出口累计同比属于 `ytd_yoy`，其原变化列各有 37 个周度锚点连接了两年的累计口径。Z* 在同一年内计算趋势和变化，年初先保留水平，待有本年可比期再生成变化。两列的具体锚点记录在机器可读质量报告中。
- 原进出口谱系各有 73 次同一经济期的来源更替，已准入数值一致。重刊可能更新原 `age_days`，Z* 的事件和年龄沿用该期最早有据的可得时间。保存原封版与原 Z 后，历史 Elastic Net、RBF-SVM 主实验，以及 60 日和纯宏观扩展中使用相应原列的结果仍归属原 Z。
- `gdp_real_yoy` 有 20 个经济期出现多个不同版本值，外汇储备有 49 个。水平项保留该时点已准入的最新版本，趋势、发布创新和发布时钟固定为最早有据版本。只有在某期发布前已经有据的期次才可进入其预测历史。同一时点披露的历史期次、显式后编年表及事后口径回溯不会填成当期预测创新。
- DR007 的 607 个周度锚点中，593 个使用准入的历史供应商报价快照重建，14 个使用保守时点重建。原始报价更正档案不完整。Z* 的 DR007 水平、变化、波动和压力分位承继这一限制。物价、GDP 和 PMI 主系列的历史版本依据与报价数据不同，详见逐期与逐特征谱系。

## 表示与数据边界

- 增长和价格采用最新水平、实际发布顺序上的相邻变化、三期趋势和历史预测创新。创新基准是发布前已知、口径可比的前三期均值。部分序列以此前 6–12 个合格创新的标准差归一。现有来源无时点可证的发布前市场一致预期，创新字段以历史预测为基准。
- M2 与社融增长率只在同一经济期进行比较。社融不同制度口径各自保留，极短口径仍留在原 Z。新增贷款以同口径上年同月为季节性基期，旧口径没有适用比较时保留缺失。
- 日度利率、期限利差和汇率沿用已有观察窗口。DR007 压力以此前 252 个已知报价的经验中位秩衡量。增长广度包含 PMI 是否高于 50，价格动量为 CPI 和 PPI 同比变化的平均，信用资金组合使用 M2 趋势与 DR007 压力，外部压力依据人民币贬值与外储同比下降是否同时出现。
- 公告事件由上一周度锚点后首次进入当前最新经济期的记录触发。已公布值持有时，事件记 0，创新无历史支持时保留缺失。发布时间共用的 PMI、生产消费、物价与外贸组合共享一列年龄与事件，实际数值与创新仍按原指标区分。
- `lineage.parquet` 逐周逐列保存父记录 ID、最大父记录可得时间和缺失状态。来源和变换在 `feature_catalog.json` 登记。所有父记录通过 `available_at <= asof_time` 检查。宏观缺失没有删减配对样本，填补和常数处理在训练折内部完成。

## 数值覆盖

纯宏观 Z* 有 114 列，含原 Z 的 34 列及新增的 80 列。按增长、物价、信用、利率、外部分别为 35、15、32、16、16 列。全期每列至少有两个不同观测值。初始训练窗的 251 个锚点中，103 列有变化，11 列全空，主要来自后来开始的新统计口径。原 Z 的 224 列在该初始窗有 13 列全空、85 列恒定。扩展训练窗按市场有 103–114 列具备观测变化。初始训练期在至少 40 个共同有效观测条件下没有绝对 Pearson 相关达到 0.995 的列对。质量检查未使用标签或模型成绩。

机器可读审计和数据位于 `data/market_state/release/z_star/`。`quality_report.json` 保存逐列覆盖率、训练方差、宽松箱线阈值所标记的观测数、各折有效维度、源系列统计及历史错误锚点。正式实验使用已封存的数据文件，无需访问 E 盘或原始数据湖。
